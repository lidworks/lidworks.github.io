Install

Set up in a minute.

  1. Download and open WipeMode.dmg, then drag WipeMode into Applications.
  2. Open it once. If macOS says it can't check the app, click Done, then go to System Settings → Privacy & Security and click Open Anyway.
  3. Allow Accessibility. macOS asks for this before any app can block input. Turn on WipeMode in Privacy & Security → Accessibility.
  4. Press ⌃ ⌥ ⌘ W and wipe. Hold both ⌘ keys when you're done.

Why the extra click in step 2? WipeMode isn't notarized by Apple yet, so macOS asks you to confirm the first time. It's a one-time step; the app is the same tiny program either way.

FAQ

Questions

Does it block the touchscreen on the new MacBook Pro?

Yes. While WipeMode is on, the whole screen is a black window that ignores every tap and swipe, on top of the input lock.

What if I can't get out?

Hold both ⌘ keys for 1.5 seconds. If that doesn't work for any reason, WipeMode exits by itself when the timer runs out (2 minutes at most). And if the app ever freezes, a watchdog quits it, which instantly gives you your keyboard back.

Why does it need Accessibility permission?

macOS only lets apps with this permission block keyboard and trackpad input. WipeMode uses it for nothing else: it doesn't record keys and has no network access. Without it, WipeMode can still black out the screen.

Can it stop the power / Touch ID button?

No. That button is handled by the hardware, so pressing it will still lock your Mac. Everything else is blocked.

My menu bar is full and I can't see the WipeMode icon.

It's probably hidden behind the camera housing. Open WipeMode again from Applications and its menu pops up right where your pointer is. The shortcut always works too.
