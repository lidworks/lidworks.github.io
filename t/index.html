Install

Four steps.

  1. Open the downloaded .dmg and drag Strip to Applications. (Strip is the app’s name on your Mac; Lidkeys is the product name.)
  2. Open Strip from Applications. macOS says it can’t check it for malicious software: click Done — not Move to Trash. This build is signed with the Lidworks certificate but not notarized by Apple.
  3. Open System Settings → Privacy & Security, scroll down and click Open Anyway. (Right-click → Open no longer works on current macOS.) Or run xattr -dr com.apple.quarantine /Applications/Strip.app in Terminal.
  4. Strip shows a short welcome and asks for Accessibility permission, so it can read and press the front app’s menu commands. Emoji and the word count while typing also need Input Monitoring; it asks the first time you type in a chat app.

On macOS 27.3, macOS also asks before Strip can control each app. Choose Allow. To stop being asked for an app: System Settings › Privacy & Security › System & App Protection Override › Strip, and set that app to At Any Time.
